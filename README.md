### Controls
 - ```esc```: quit
 - ```space```: pause/unpause
 - ```right arrow```: single step
 - ```mouse```:
   - right click and drag to change view angle
   - scroll to zoom in/out
 - ```=```: add point
 - ```-```: remove point
 - ```F3```: show axis, surface sphere
